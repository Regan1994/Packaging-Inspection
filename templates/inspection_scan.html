掃描操作說明

1. 開始校機員工條碼 → 訂單 START
2. 完成校機原認領員工條碼 → 訂單 FINISH
3. 機台缺料原認領員工條碼 → 固定缺料條碼 → 該訂單 START
4. 料件補齊原認領員工條碼 → 固定補料條碼 → 該訂單 START
  • 缺料／補料流程中的 START 條碼只用來指定機台，不會重新開始訂單。
  • 缺料期間停止計算實際工時；缺料中不能 FINISH，必須先完成補料掃描。
  • 誤掃員工可直接掃正確員工；誤選員工、缺料或補料，也可按「清除／更換人員」重新操作。
  • 完成一筆訂單操作後，系統會清除目前員工，下一次需重新掃員工條碼。
