# 使用者快速指南

## 連線與管理密碼

由主機啟動系統後，主機本機開啟 `http://127.0.0.1:5000/`；其他印表機或掃碼電腦開啟 `http://主機IP:5000/`。所有電腦必須連到同一主機，不可各自啟動系統，才能共用 `instance/inspection.db`。

首頁的掃描功能可直接使用；訂單、人員、機型、報表、設定及清除資料需要管理密碼。初始密碼為 `TJR`。設定頁可更改密碼，也可暫時停用功能密碼；排查完成後請重新啟用。

## 建立訂單與列印

1. 到「機型管理」建立或確認啟用中的機型；只需輸入機型名稱，軸別由系統依規則自動判斷，內部代碼也由系統自動處理。
2. 到「校機人員」輸入唯一員工編號與姓名，建立後列印員工條碼。
3. 到「建立訂單」輸入唯一訂單號碼、機型及機台製號。建立訂單時不指定校機人員；客戶、預計出貨日及重新檢驗原因目前可選填。
4. 系統建立一張待校機訂單，並產生專用 START／FINISH 短版條碼。訂單號碼必須唯一，但同一機台製號可出現在多張訂單。
5. 訂單條碼與員工條碼列印頁均以單張 60×60 mm 標籤為目標；列印請選擇 60×60 mm、實際大小／100%。

## 現場掃描

每次操作都使用兩段掃描：

1. 掃員工條碼，畫面顯示姓名與員工編號。
2. 再掃該訂單的 START 或 FINISH 條碼。

掃 START 時才認領訂單並改為「校機中」；FINISH 預設只能由原認領人員完成。訂單條碼處理後會清除瀏覽器暫存的員工身分，下一張訂單必須重新掃員工條碼。停用員工、未先掃員工、FINISH 早於 START、其他員工接手及重複掃描都會被拒絕或提示為重複。

掃描器請使用 USB HID、掃描後送出 Enter，並在掃描頁保持輸入框焦點。

## 報表、重印與資料安全

報表下方的「訂單明細」可查看狀態並進入編輯頁；編輯頁可列印原訂單 Code、取消訂單或刪除尚未開始的誤建訂單。重印不建立新訂單。報表可依訂單號碼、機型、軸別、機台製號、員工、狀態查詢，並顯示四軸／五軸統計，也可匯出包含人員統計、軸別統計與訂單明細的 Excel。依機台製號查詢時，會列出該機台的所有歷次校機訂單。

軸別判斷規則是：機型名稱 F 或 M 開頭，或機台製號 S 開頭，判定為五軸；其他判定為四軸。英文字母不分大小寫，前後空白會忽略。

校機人員頁可直接編輯員工編號與姓名；沒有歷史訂單的人員可刪除，有歷史訂單的人員請改用停用。報表的訂單明細編輯頁可取消待校機或校機中的訂單，或刪除尚未開始的誤建訂單。刪除前會先建立備份並要求確認；已開始或已完成的訂單會保留，避免破壞歷史報工。

「清除資料」只供除錯。勾選資料分類並輸入「清除」後，系統會先建立並驗證完整 SQLite 備份，再清除所選資料；稽核紀錄與既有備份不會被清除。正式資料也會被清除，執行前請確認範圍。
