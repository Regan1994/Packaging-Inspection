- Windows 全域命名 Mutex：同一主機只允許一個主系統程序；重複啟動會開啟既有網址並通知，不會先開啟 SQLite。

### 閱讀器與主機報表

- `/manager` 保留原搜尋條件及唯讀明細；表格每頁 25 台，只顯示指定欄位。
- 閱讀器「下載 Excel」與主機報表使用同一份完整 Excel，包含人員統計、訂單明細、軸別統計三個工作表。
- 實際工時可計時段：08:00–12:00、13:00–17:00；同日 START 或 FINISH 在 17:30 以後，另計 17:30–20:30。週末僅在該日有 08:00 後 START 或 FINISH 時納入。

### 本次重要修正：人工／缺料暫停

原問題：跨週末、午休或下班的人工暫停，系統把「暫停總秒數」直接從可計工時扣除，可能將實際校機工時壓成 `00:00:00`。

現已修正為：

- 只扣除每段缺料／人工暫停和可計工時區間實際重疊的秒數。
- 若歷史資料有重疊的暫停紀錄，重疊部分只扣一次。
- 主機訂單頁、主機報表、閱讀器表格／明細與 Excel 都使用相同算法。
- 截圖中的案例（START：2026-10-30 16:30:41；人工暫停：2026-11-02 11:38:40 至 2026-11-03 10:21:44）修正後預期實際工時為 `04:07:59`，不再是 `00:00:00`。

## 正式部署規則

正式資料庫位於發布資料夾的 `instance\inspection.db`。更新時：

1. 關閉舊的 `InspectionReporting.exe`。
2. 備份舊版完整 `instance` 資料夾。
3. 解壓新版完整 onedir 發布包，不能只複製 EXE。
4. 將原本正式 `instance` 帶回新版資料夾；不能讓發布包的空資料夾覆蓋它。
5. 只啟動一個 `InspectionReporting.exe`，再從閱讀器確認該訂單的實際工時。
