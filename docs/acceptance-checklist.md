# 校機報工驗收清單

- [ ] 主機依 README 啟動並監聽 `0.0.0.0:5000`；本機可用 `127.0.0.1`，其他電腦可用主機區網 IP。
- [ ] 主機只建立／使用 `instance/inspection.db`；印表機與掃碼電腦連到同一主機網址，不各自啟動系統。
- [ ] 可建立啟用中的機型、校機人員及唯一員工編號；可列印單張或多張員工 Code128 條碼。
- [ ] 軸別依規則自動判斷：機型 F／M 開頭或製號 S 開頭為五軸，其他為四軸；首頁與報表可顯示兩類台數，Excel 包含軸別統計。
- [ ] 建立訂單時輸入唯一訂單號碼、機型及機台製號，不要求先指定校機人員。
- [ ] 同一機台製號可建立多張不同訂單；訂單號碼重複時拒絕且不覆蓋既有訂單。
- [ ] 訂單建立後產生專用 START／FINISH 短版條碼，payload 長度為 12 字元，重印內容不變。
- [ ] 訂單與員工條碼頁以單張 60×60 mm 標籤列印；實際大小／100% 時文字與條碼不超出標籤。
- [ ] USB HID 掃描可完成「員工條碼 → START → 員工條碼 → FINISH」，狀態依序為待校機 → 校機中 → 已完成。
- [ ] 未先掃員工、停用員工、未開始直接 FINISH、其他員工 FINISH、重複掃描及無效條碼均有正確提示且不誤改資料。
- [ ] 訂單條碼處理後清除暫存員工；下一張訂單需重新掃員工條碼。
- [ ] 同一製號查詢會列出所有歷次訂單；報表支援訂單、機型、製號、人員及狀態篩選。
- [ ] 報表訂單明細可刪除尚未開始的誤建訂單；刪除前自動備份並保留稽核紀錄，已開始或已完成訂單不可刪除。
- [ ] Excel 匯出為每位人員建立軸別機型分頁，並包含軸別統計與訂單明細；使用者輸入以公式開頭時不會被 Excel 當作公式執行。
- [ ] 備份檔可通過 SQLite `integrity_check`；還原前會建立安全備份。
- [ ] 清除資料需輸入「清除」，執行前備份且保留稽核紀錄；外鍵關聯不被破壞。
- [ ] 現場實測 Windows 防火牆、60×60 mm 熱感印表機及 USB HID 掃描器。
- [ ] 客戶／出貨欄位與「不同員工接手校機中訂單」流程經現場確認後，再更新需求與決策文件。
