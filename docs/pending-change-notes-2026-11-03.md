# 校機報工待修改需求紀錄

更新日期：2026-11-03

本文件記錄已確認的需求方向與完成結果。

## 已確認：Excel 人員個別分頁版面

- 移除目前 Excel 的單一「人員軸別機型」摘要分頁及無用途的完成率概念。
- 改為每位校機人員各自一張 Excel 工作表。
- 每張人員工作表需清楚列出：
  - 四軸總台數，以及各機型分別幾台。
  - 五軸總台數，以及各機型分別幾台。
- 工作表以「軸別、機型、台數」的表格呈現，四軸與五軸各有小計。
- 使用者已確認「人員個別 Excel 分頁示意」的版面方向。

## 已確認的實作細節

- 未認領訂單另外產生一張「未認領」工作表。
- 已取消訂單排除於人員軸別與機型台數之外。
- 工作表名稱使用人員姓名；若名稱不符合 Excel 限制或重複，系統會自動安全調整名稱。
- 已於 `V701.11.03` 實作；另保留「訂單明細」與「軸別統計」工作表。
