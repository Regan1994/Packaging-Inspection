# Bug 觀察紀錄

日期：2026-10-28

## 訂單建立後清單顯示異常

現場觀察流程：

1. 直接建立新訂單，輸入新的機台製號與尚未建立的機型。
2. 系統成功產生訂單條碼。
3. 到訂單／報表清單查看時，找不到這台機台或這筆訂單。
4. 手動建立或更新該機型。
5. 再次輸入同一筆訂單。
6. 系統沒有顯示「訂單號碼已存在」錯誤，反而再次成功產生條碼。
7. 第二次建立後，這台機台／訂單才出現在清單中。

待確認重點：

- 第一次建立的訂單是否真的寫入與清單查詢相同的 SQLite 資料庫。
- 兩次輸入的訂單號碼是否完全相同（包含大小寫、前後空白與特殊字元）。
- 第一次與第二次操作是否實際連到同一個主系統程序與資料庫。
- 條碼產生成功但清單查不到的時間點，是否是頁面查詢或資料庫連線未更新。
- 若兩次訂單號碼完全相同，第二次應該被唯一性檢查拒絕，不應再次產生條碼。
